# Documentation diagrams

Each diagram's `.svg` file is its editable source. Edit its text, colors and layout in an SVG editor or a text editor. The diagrams use Segoe UI, with Arial as a fallback, and contain no external resources.

Export each SVG to PNG at twice its intrinsic size, replacing the matching PNG:

| Source | PNG size | Display width in API.md |
| --- | --- | --- |

| HandLayout.svg | 1800 x 864 | 760 px |

The API guide embeds PNGs for Markdown viewer compatibility, with alt text describing each flow. Keep the PNG and SVG together, and preserve their Unity `.meta` files when copying them between projects.
